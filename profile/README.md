The optimaru project develops open-source tools to solve real-world combinatorial optimization problems — scheduling, routing and assignment — all the way from the solver engine to the apps people use every day.
These include:
- [optimaru](https://github.com/optimaru/optimaru), a dependency-free, header-only C++17 metaheuristic solver engine with Python bindings and 20+ ready-to-run use cases, benchmarked against Timefold Solver and OR-Tools CP-SAT.
- [server](https://github.com/optimaru/server), an HTTP API server that stores problems and runs solver jobs.
- [web](https://github.com/optimaru/web), a web console with interactive demos for each use case.
- [timetable](https://github.com/optimaru/timetable), a timetable app for teachers, built on the school timetabling use case.
